# Grid Inventory — 테트리스식 격자 인벤토리

바닐라 인벤토리를 통째로 대체하는 SKSE 플러그인입니다. 모든 아이템이 실제
칸을 차지하는 격자(테트리스식)로 표시되며, **인벤토리 · 컨테이너(상자·시체·
동료·소매치기) · 상점** 세 화면이 같은 격자 UI로 통합됩니다.
**즐겨찾기 `Q`는 퀵 휠로 대체**되며, 원치 않으면 설정에서 꺼서 바닐라 메뉴를
그대로 되돌릴 수 있습니다. 그 외 화면(제작대 · 마법 · 선물 · 일지 · 지도 ·
TAB)은 바닐라/SkyUI 그대로입니다.

아이템 아이콘은 게임이 직접 3D 모델을 캡처해 만들기 때문에 아이콘 팩이
필요 없고, 어떤 모드 아이템이든 패치 없이 자동 지원됩니다.

---

## 요구 사항

| 항목 | 내용 |
|------|------|
| 게임 | Skyrim Special Edition / Anniversary Edition (1.5.x ~ 1.6.x 전 버전) |
| 필수 | [SKSE64](https://skse.silverlock.org/) |
| 필수 | [Address Library for SKSE Plugins](https://www.nexusmods.com/skyrimspecialedition/mods/32444) — 구매 여부가 아니라 **exe 버전**에 맞는 파일을 받으세요: 1.6.x는 *All in one (AE)*, 1.5.97은 *(SE)*. 반대로 받으면 실행 시 `failed to open address library file`로 멈춥니다. |

CommonLibSSE-NG 기반으로 SE/AE 전 런타임을 단일 DLL로 지원합니다.
**SkyUI · MCM은 지원 대상이 아닙니다.**
게임패드는 지원합니다 — 왼쪽 스틱이 **게임 커서**를 움직이고(게임의 커서 감도
설정을 그대로 따릅니다), 오른쪽 스틱은 스크롤, 방향키는 한 칸씩 이동입니다.
버튼은 **게임의 조작 설정을 따릅니다**: 확인=집기/놓기, 장착=착용·읽기,
버리기/전부 담기, 즐겨찾기, 아이템 확대=3D 보기. 조작키를 바꾸면 같이 바뀌고,
Xbox 배열이 아닌 패드도 자동으로 맞습니다. 마우스를 움직이면 즉시 마우스로 돌아옵니다.

## 설치

모드 매니저(MO2, Vortex)로 아카이브를 설치하면 끝입니다. 구성 파일:

```
Grid Inventory.esp          (코인/주머니 + 가방 18종 폼 + 과적 처리 능력 2종 + UI 효과음)
SKSE/Plugins/GridInventory.dll
SKSE/Plugins/GridInventory_icons.pak      (바닐라+AE CC 전 아이템 아이콘 사전 캡처본)
SKSE/Plugins/GridInventory_items.ini      (전 아이템 칸 크기·회전 튜닝값)
SKSE/Plugins/GridInventory_categories.ini (카테고리 기본값 — 목록에 없는 아이템용)
SKSE/Plugins/GridInventory_slots/         (장비 슬롯 실루엣)
SKSE/Plugins/GridInventory_fallback/      (그림 아이콘 PNG — 원하는 그림으로 교체 가능)
SKSE/Plugins/GridInventory_lang/          (언어 — 한/중/일/영, 직접 추가 가능)
meshes/, textures/, Sound/  (코인 모델·효과음)
```

나머지 설정 파일(`_ui.ini` 등)은 첫 실행 후 `SKSE/Plugins/`에 자동 생성됩니다.
미리 손볼 ini는 없습니다. 진행 중인 세이브에 설치해도 됩니다.

## 첫 실행

1. **바닐라·AE 크리에이션 클럽 아이템은 아이콘이 미리 동봉**되어 있어 캐싱
   대기 없이 바로 보입니다. 모드 아이템만 처음 화면에 보일 때 캡처됩니다 —
   격자 위 **'아이템' 라벨 옆에 "아이콘 캐싱 중… N"** 카운터가 표시됩니다.
2. **기본 언어는 영어**입니다. 설정 → 언어 → 한국어.
3. (모드 아이템이 많다면 권장) 설정 → 아이콘 → **전체 사전 캐싱** — 인벤토리를
   열어 둔 동안 한 프레임에 하나씩 전 아이템을 미리 캡처합니다(창을 닫으면 저장 후 중단).

## 기능

### 격자 인벤토리
- 10×14 = **140칸 고정**. 아이템마다 실제 칸 크기(1×1 반지 ~ 2×4 대형무기),
  자유 모양(ㄱ자 등) 풋프린트 지원. **들고 있을 때 `A`/`D`로 90도 회전**합니다.
  자동 정렬과 검색은 없습니다 — 직접 정리하는 재미가 이 모드의 핵심입니다.
- **집었다 놓기** 방식: 좌클릭으로 들고, 놓을 칸에서 다시 좌클릭(스왑 지원).
  Shift+좌클릭 = 스택/골드 분할 슬라이더.
- 후광으로 등급 표시(**유니크 = 빨강 · 인챈트 = 파랑**), 독은 우상단 물방울,
  마커(즐겨찾기 ◆ / 퀘스트 ▲ / 장물 ●), **최근 획득한 칸은 옅게 밝아짐**,
  Shift 비교 툴팁('착용 중' 카드 포함).
- **용량**: 140칸 초과 시 과적존 표시 + 이동 감속. 가득 차면 습득 차단
  (퀘스트·스크립트 지급 아이템은 일부러 막지 않고 과적으로 들어옵니다).
- **`C` 3D 살펴보기**: 회전·확대로 모델 디테일 확인(드래곤 발톱 문양 등).
  내 격자 · 장비창 · 상자/상인 칸 어디서나 됩니다. **가장 작은 배율로 열립니다.**
- **장비 인형**: 착용 슬롯 17칸, 놓아서 장착 / 우클릭 해제.
- **반지 두 개**: 바닐라는 하나뿐이지만 여기서는 둘까지 낍니다.
  - 첫 번째는 평소대로 **클릭**하면 왼쪽 반지 칸에 들어갑니다.
  - 두 번째는 **오른쪽 반지 칸에 끌어다 놓아야** 합니다. 클릭으로는 안 들어갑니다 —
    반지가 계속 첫 칸을 갈아치우는 일을 막기 위해서입니다.
  - **같은 효과의 반지 두 개는 낄 수 없습니다.** 등급만 다른 같은 계열도 막힙니다
    (마법 효과로 판정하므로, 이름이나 등급이 달라도 효과가 겹치면 칸이 받지 않습니다).
  - 왼쪽 반지를 오른쪽 칸에 끌어다 놓으면 **두 반지가 자리를 바꿉니다.**
  - 두 번째 반지의 **효과는 정상 적용되지만 모습은 손에 보이지 않습니다.** 반지 메시가
    자기 슬롯 번호를 파일 안에 갖고 있어서, 같은 번호를 첫 반지가 쓰는 한
    두 번째는 그려질 수 없습니다. 게임 쪽 제약이라 이 모드에서 해결할 수 없습니다.
- **장비 세트 탭**: 탭 클릭 = 그 세트로 통째 갈아입기(실제 장착, 능력치 반영).
  비활성 탭의 장비는 격자에 안 보이고 칸도 차지하지 않습니다.
- **가방 18종**: 우클릭하면 내부 격자가 열립니다.
  - **범용 12종** — 1칸짜리 작은 주머니부터 3×3에 100칸을 담는 탐험 배낭까지.
    잡화상이 재입고 주기마다 3종씩 진열을 바꿉니다.
  - **분류 전용 6종** — 연금 재료·광석과 주괴·가죽·물약·소울 젬·열쇠(락픽 포함).
    그 분류만 들어가고, **주우면 곧바로 해당 가방으로 들어갑니다.** 꺼내 둔 것은
    그 자리에 남습니다. 제목 줄의 **「모으기」**를 누르면 흩어진 것을 불러옵니다.
    그 물건을 취급하는 상인이 늘 갖고 있습니다(연금술사에게 연금 가방).
  - 전용 가방의 칸은 사용 공간 수치에서 빠집니다 — 일반 짐을 넣을 수 없으니까요.
  - EDIT 모드로 다른 아이템도 가방으로 지정할 수 있습니다(최대 16×16).
- **휴지통**: 6×4 대기함. 우클릭으로 되돌리기, **창을 닫는 순간 삭제 확정**.

### 골드 실물화
- 골드가 1,000G당 1칸씩 실물 코인 타일로 표시됩니다.
- **코인 파우치**(2×2, 잡화상 판매): 최대 10,000G. 보유 중 새로 얻는 골드
  자동 저장, 우클릭 슬라이더 인출. 저금이 아니라 총 소지금에 포함됩니다.
- 코인을 창밖에 놓거나 `R` = 금액별 주머니가 바닥에 실물로 떨어짐.

### 컨테이너 / 상점 / 소매치기
- 상자·시체·동료가 같은 격자로 열리고, **보관 위치가 기억됩니다**
  (컨테이너 128개 한도, 꺼낸 자리는 빈칸으로 예약).
- 상점: 흥정가 적용, **강화 수치까지 반영된 개체별 가격**, 상인 소지금 표시,
  수량 슬라이더 + **최대** 버튼, 말솜씨 경험치 정상 지급.
- 소매치기: 칸마다 성공률 %(묶음 전체 기준), 착용 장비 잠금(퍼펙트 터치로
  해제), 역소매치기 + Poisoned 퍼크 독 심기.
- 잠금해제 성공 시 자동 열림(QuickLoot 계열 위젯이 있으면 그쪽에 양보).

### 퀵 휠 — 인벤토리를 열지 않고 바꾸기

게임의 **즐겨찾기 키(기본 `Q`)를 누르고 있으면** 화면이 물러나며 10칸 원이
펼쳐집니다. **바닐라 즐겨찾기 메뉴를 대신하는 기능**이라 같은 키에 답하고,
그 키를 게임 조작키 설정에서 바꾸면 휠도 따라갑니다.

- **`A` / `D`로 그룹 전환** — 네 가지가 있습니다.

  | 그룹 | 내용 |
  |---|---|
  | PRESET | 장비 세트 탭 — 고르면 그 세트로 갈아입습니다 |
  | COSTUME | 같은 탭의 **외형만** 입기 (아래 참조) |
  | GEAR | 별을 붙인 무기·방어구·물약 |
  | MAGIC | 별을 붙인 주문·외침 |

- **고르는 법**: 마우스 휠을 굴리거나 그냥 마우스를 그 방향으로 움직입니다.
  **키를 놓으면 적용**됩니다. 게임패드는 왼쪽 스틱으로 조준, D-패드 좌우로 그룹.
- **아무것도 고르지 않으려면** 커서를 가운데로 되돌리고 놓으면 됩니다.
  가운데에서는 지나간 자리에 먹 자국이 남아 손이 어디 있는지 보입니다.
- **GEAR / MAGIC은 클릭으로도** — 좌클릭은 오른손, 우클릭은 왼손.
  물약처럼 손에 드는 물건이 아니면 그냥 사용됩니다. 이미 착용한 것을 다시
  고르면 해제됩니다.
- **자리 옮기기**: 칸을 왼쪽 버튼으로 집어 끌면 지나가는 이웃이 하나씩
  비켜섭니다. 놓은 자리는 세이브에 남고, **정리한 방문은 아무것도 적용하지
  않습니다.** 그룹마다 배치를 따로 기억하며, 인벤토리 탭 순서는 바뀌지 않습니다.
- **별을 붙이는 것이 곧 등록**입니다 — 인벤토리에서 `F`, 또는 마법 메뉴에서
  게임의 즐겨찾기 지정. 휠에 따로 등록하는 절차는 없습니다.
- **끌 수 있습니다** — 설정의 **QUICK WHEEL**을 끄면 바닐라 즐겨찾기 메뉴가
  그대로 돌아옵니다(숫자키 단축키 지정 포함). 휠의 배치는 지워지지 않고
  남아 있다가 다시 켜면 그 자리 그대로입니다.

### 코스튬 — 능력치는 그대로, 외형만 갈아입기

장비 세트 탭 하나를 **외형 공급원**으로 지정하면, 실제로 착용한 장비의
성능은 그대로 두고 겉모습만 그 탭의 것으로 보입니다.

- 인벤토리의 탭에 있는 표식을 눌러 지정하고, 퀵 휠의 **COSTUME** 그룹에서도
  바꿀 수 있습니다. 한 번에 하나만 — 새로 고르면 이전 것은 해제됩니다.
- **EQUIP를 고르면 코스튬이 벗겨집니다.** 원래 장비가 그대로 보입니다.
  (장비를 EQUIP 세트로 바꾸는 것이 아닙니다 — 그건 PRESET 쪽 일입니다.)
- 방어도·인챈트·강화·퍽은 **실제 착용 장비의 것**입니다. 겉모습을 빌려 오는
  동안에도 착용 상태는 한순간도 풀리지 않습니다.
- 현재 입고 있는 세트는 코스튬으로 고를 수 없습니다(같은 것을 겹쳐 입는 셈).

### 설정 (타이틀바 SETTINGS)
- 크기, 스킨 19종(먹선 2종 포함), 언어(실시간 전환), 아이콘 밝기·
  스타일, 아이템 그림자(거리·흐림·진하기), 캡처 조명, 아이콘 캐시 초기화,
  전체 사전 캐싱, **퀵 휠 켜기/끄기**, 거래 옵션 (상인 소지금 무제한 /
  모든 품목 매입).
- 슬라이더는 드래그·양 끝 ± 버튼(길게 누르면 연속)·더블클릭 직접 입력·
  우클릭 기본값 복귀를 모두 받습니다.

### 번역 추가하기
언어는 전부 `SKSE/Plugins/GridInventory_lang/`의 텍스트 파일입니다. 동봉된
한/중/일/영과 **똑같은 자격**으로 직접 만든 번역이 목록에 올라옵니다.

1. `en.ini`를 복사해 `pl.ini` 같은 이름으로 바꿉니다.
2. 맨 위 지시어를 고칩니다.

```ini
#name  = Polski                  목록에 보일 이름
#order = 50                      목록 순서 (기본 100)
#font  = C:\Windows\Fonts\...    기본 글꼴에 없는 문자를 쓸 때만
#range = cyrillic                문자 범위 — 프리셋 또는 0x0400-0x052F

Inventory = EKWIPUNEK            왼쪽 키 이름은 그대로, 오른쪽만 번역
```

- **키 이름은 절대 바꾸지 마세요.** 위치가 아니라 이름으로 찾습니다 — 그래서
  다음 판에서 문구가 늘어도 예전 파일이 그대로 동작합니다.
- 빠뜨린 키는 영어로 나옵니다. 전부 번역하지 않아도 됩니다.
- 줄바꿈은 `\n`으로 씁니다.
- **`#range`가 `#font`보다 중요합니다.** 글꼴 파일에 글자가 있어도 범위를
  요청하지 않으면 네모로 보입니다.
- `en.ini`는 언어를 더하는 대신 영어 문구를 덮어씁니다.
- 폴더를 통째로 지우면 영어로만 동작합니다(고장나지 않습니다).
- **아이콘 스타일 3종**:
  - **리얼리스틱** — 게임 3D 모델을 그대로 캡처합니다 (기본).
  - **그림** — 손으로 그린 **종류 아이콘만** 씁니다. **캡처를 아예 하지 않아
    처음 스캔이 없고**, 메뉴를 여는 순간 전부 채워져 있습니다. 아이템 모드가
    아주 많을 때 권합니다. 종류는 **127종**이며 재질·등급별 색 변형까지
    합치면 492장입니다. 무기·방어구는 재질 16종, 주문서는 학파 5색,
    스킬북은 성좌 3계열, 물약은 효과 6색으로 갈립니다.
  - **픽셀** — 리얼리스틱 캡처를 도트로 다시 그립니다. 별도 그림이 없으므로
    **모드 아이템도 자동으로 따라옵니다.** 아이템마다 그 아이템의 색에서
    12색을 뽑아 쓰기 때문에 없던 색이 생기지 않습니다.

  셋 다 `C` 3D 보기는 그대로 됩니다. 그림 아이콘은 EDIT에서 **회전·확대·좌우
  위치**를 따로 조정할 수 있고, 그 값은 리얼리스틱 쪽과 별개로 저장됩니다.
  (픽셀은 리얼리스틱의 파생이라 회전·확대·칸 수를 그쪽과 함께 씁니다.)

- **프리셋**: 스킨·모든 아이템 정의·아이콘 그림까지 이름 붙여 저장,
  드롭다운에서 즉시 불러오기. 생성되는 `GridInventory_<이름>.ini` +
  `GridInventory_<이름>_icons.pak` 두 파일을 주고받으면 **다른 사람의 정리
  상태를 캐싱 대기 없이 그대로** 가져올 수 있습니다.

### 그림 아이콘 교체 (툴 없이)

`SKSE/Plugins/GridInventory_fallback/` 안의 **PNG를 바꿔 넣으면 그게 나옵니다.**
그 폴더의 `_README.txt`에 같은 설명이 있습니다.

| 넣는 위치 | 적용 범위 |
|---|---|
| `item\Skyrim.esm_0x012E49.png` | 그 아이템 하나 |
| `wpn_sword@steel.png` | 강철 검 전부 |
| `wpn_sword.png` | 한손검 전부 |

- **파일 이름은 인게임이 알려줍니다.** EDIT에서 아이템을 클릭하면 `아이콘 파일`
  줄에 위 두 이름이 그대로 나오고, 클릭하면 복사됩니다.
- 128×128 RGBA 권장. 정사각형이면 크기는 자유입니다.
- 직접 넣은 PNG는 **동봉 그림보다 항상 우선**합니다. 그래서 `wpn_sword.png`
  하나로 강철·흑단 등 재질 변형까지 전부 덮입니다.
- 수정 후 `F5 → 아이콘 → 그림 아이콘 → 다시 읽기`.
- ⚠️ **MO2를 쓰면 파일을 처음 넣을 때 한 번은 게임 재시작이 필요합니다.** MO2는
  실행 시점에 파일 목록을 만들기 때문에, 실행 중에 추가한 파일은 게임에 보이지
  않습니다. 한 번 재시작한 뒤로는 그 파일을 고칠 때마다 「다시 읽기」로 바로
  반영됩니다.

### 편집 (타이틀바 EDIT)
- 아이템 클릭 → 회전·이동(탭 전환)/크기/칸 모양(8×8 페인터, 자유 도형)/
  캡처 조명/가방/스택 편집, 카테고리 기본값 저장. 결과는 프리셋으로 공유합니다.

## 조작법

| 입력 | 동작 |
|------|------|
| 인벤토리 키 (기본 `I`) | 열기 / 닫기 — 게임 조작키 설정을 따릅니다 |
| 즐겨찾기 키 (기본 `Q`, 홀드) | **퀵 휠** — 휠/마우스로 고르고 놓으면 적용 · `A`/`D` 그룹 · 좌·우클릭 = 오른손·왼손 · 끌어서 자리 이동 |
| 좌클릭 | 집기 → 놓을 칸에서 다시 좌클릭 (다른 아이템 위 = 스왑) |
| 우클릭 | 장착·사용 / 가방 열기 / 파우치 인출 · (루팅/상점/소매치기 창) 보관·판매·심기 · (들고 있을 때) 취소 |
| Shift+좌클릭 | 스택·골드 분할 슬라이더 |
| `A` / `D` (들고 있을 때) | 회전 — `A` 반시계 / `D` 시계, 90도씩. 칸 모양이 바뀌는 아이템만 |
| 수량 창에서 | `A`/`D`·`←`/`→` 1씩 조절 · **최대** 버튼 · `Enter`/`Space` 확인 · `ESC` 취소 |
| Shift (홀드) | 착용 장비와 비교 |
| `C` | 3D 살펴보기 — 내 격자 · 장비창 · 상자/상인 칸 어디서나. 드래그 회전 · 휠 확대 · `R` 초기화 |
| `R` | (내 격자) 1개 버리기 / (상자 창) 전량 획득 |
| `F` | 즐겨찾기 — 퀵 휠의 GEAR 그룹에 바로 들어갑니다 |
| 창밖 드랍 | 버리기 (상자·상점 창이 열려 있으면 취소됨) |
| `ESC` | 위부터 한 겹씩: 3D 살펴보기 → 확인·수량 창 → 휴지통 → 파우치 → 설정 → EDIT → 인벤토리. 아이템을 들고 있으면 '들기 취소'가 먼저 |

## 알아둘 사양

- **인벤토리를 열면 게임이 멈춥니다** (Skyrim Souls RE 계열과 상충).
- **Book 'em 등 "책 읽기 개편" 모드와 주문서 학습이 비호환**입니다 — 스카이림의
  메뉴 내 읽기는 호출 가능한 API가 아니라서, 이 모드는 주문서를 직접 배우고
  소비합니다. 책 개편 모드의 후킹(미소비·분할 학습 등)은 우리 화면을 지나지
  않습니다. 일반 책·노트·스크롤·엘더스크롤은 엔진 경로를 그대로 타므로 영향이
  없고, 월드에 놓고 읽는 책은 전부 정상 적용됩니다.
- **무게 제한은 소지 한계를 크게 올리는 방식으로 해제**됩니다 — 무게·짐
  관리 모드와 어긋납니다. 모드를 지우면 효과는 자동으로 사라집니다.
- ⚠️ **골드 든 파우치를 리스폰되는 컨테이너에 두면 파우치와 골드가 함께
  사라집니다.** 집 컨테이너에만 보관하세요. 파우치 보관액·바닥 주머니
  금액은 코세이브에만 있으므로, **모드 제거 전에 회수**하세요.
- 파우치 판매 시 저장 골드는 자동 인출되고 빈 파우치만 팔립니다.
- 리텍스처 교체 후에는 설정 → 아이콘 캐시 **초기화**로 재캡처하세요.
- 자체 단축키 설정은 없습니다 — 인벤토리는 게임의 **인벤토리** 키, 퀵 휠은
  게임의 **즐겨찾기** 키를 그대로 씁니다. 바꾸려면 게임 조작키 설정에서 바꾸세요.
- 한/중/일 표시는 윈도우 시스템 글꼴을 사용합니다(글꼴 미동봉).
- 언어 파일을 지워도 영어로 정상 작동합니다. 직접 만든 번역은 모드 업데이트 시
  덮이지 않도록 `GridInventory_lang\`에서 따로 백업해 두세요.
- 파피루스 스크립트 0개 — 스크립트 부하·세이브 잔재가 없습니다.
- 자동 생성 파일(MO2는 Overwrite): `GridInventory_ui.ini`(설정·창 위치),
  내보낸 프리셋 파일들.
  동봉된 `_items.ini`·`_categories.ini`·`_icons.pak`는 게임 중 갱신됩니다
  (EDIT 수정, 새 캡처) — 모드 업데이트 시 덮이므로 **내 튜닝은 프리셋으로
  백업**하세요.
